# Zend Framework 1 for PHP 7.4

This is an updated version of the Zend Framework 1 package adapted to work with PHP 7.4.

## Background

Zend Framework 1 (ZF1) officially ended its life on September 28, 2016. However, many applications still rely on it, and with PHP moving forward, compatibility issues have emerged.

This package aims to provide a PHP 7.4 compatible version of Zend Framework 1, allowing legacy applications to continue functioning on modern PHP environments.

## Installation

```bash
composer require shubhamc4/zf1
```

## Requirements

- PHP 7.4 or higher
